# Engineer Ahmed Portfolio

Professional portfolio website for Engineer Ahmed - Architect and Planner.

## Features

- Responsive design with mobile-first approach
- Bilingual support (Arabic/English)
- Interactive hero section with image reveal effects
- Modern UI built with Material-UI (MUI)
- Optimized for performance with Next.js

## Tech Stack

- **Framework:** Next.js 15
- **UI Library:** Material-UI (MUI)
- **Icons:** MUI Icons, Lucide React, FontAwesome
- **Styling:** Emotion (CSS-in-JS)
- **Language:** JavaScript/React

## Getting Started

1. Install dependencies:
```bash
npm install
```

2. Run the development server:
```bash
npm run dev
```

3. Open [http://localhost:3000](http://localhost:3000) in your browser.

## Scripts

- `npm run dev` - Start development server
- `npm run build` - Build for production
- `npm run start` - Start production server
- `npm run lint` - Run ESLint
- `npm run lint:fix` - Fix ESLint issues
